# Sainath Chavan — Performance Marketing Portfolio

## Files
- index.html
- style.css
- script.js

## Run in VS Code
1. Put all 3 files in the same folder.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. All portfolio images are loaded from the image-hosting URLs you supplied.

## IMPORTANT: Add your phone/WhatsApp number
Search `91XXXXXXXXXX` in `index.html` and replace it with your real number.
Example:
- Call: `tel:+9197653156`
- WhatsApp: `https://wa.me/91976531517`

The page intentionally has no top navigation menu and uses sticky Call + WhatsApp buttons.
